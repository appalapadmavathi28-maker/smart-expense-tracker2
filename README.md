# Smart Expense Tracker

A feature-rich, self-contained **Smart Expense Tracker** web application designed to help users effortlessly manage their finances, track monthly budgets, and analyze spending habits.

## 🚀 Features

- **User Authentication:** Secure Login and Sign Up functionality using local persistence.
- **Financial Dashboard:** Real-time summary of Total Expenses, Monthly Budget, and Remaining Budget with recent transaction logs.
- **Expense Management:** Add, edit, delete, search, and filter expenses by category and description.
- **Monthly Budgets:** Set and monitor budget limits with visual progress indicators.
- **Smart Analytics:** Interactive charts (Doughnut and Bar charts powered by Chart.js) for category-wise breakdown and monthly trends.
- **Data Backup & Import:** Export your expense history as a CSV file or import past records seamlessly.

## 🛠️ Technologies Used

- **HTML5 & Tailwind CSS** — For modern, responsive styling and layout.
- **JavaScript (Vanilla JS)** — For application logic, authentication, and state management.
- **Chart.js** — For visual analytics and insights.
- **FontAwesome** — For clean UI icons.
- **Browser LocalStorage** — For persistent client-side data storage without requiring a backend server.
